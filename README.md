# SeaBlitz — «Морской блиц» 5x5

Сверхбыстрые дуэли морского боя в Telegram Mini App: поле 5x5, флот 3+2+1,
**одновременные залпы** по 3 выстрела за 10-секундный раунд.

## Статус

- ✅ **Шаг 1 — игровое ядро** (`app/game`): генерация расстановки, поле,
  развязка раунда, «Золотой раунд» при обоюдном KO. Полностью покрыто тестами.
- ✅ **Шаг 2 — WebSocket-комнаты** (`app/net`, `app/main.py`): дуэль в реальном
  времени, серверо-авторитетные таймеры, быстрый матч, вход по коду комнаты.
- ✅ **Шаг 3 — фронтенд Mini App** (`static/`): сетки 5×5, выбор клеток,
  «ОГОНЬ!», таймер, анимации, HapticFeedback, экран результата. (прототип)
- ⏳ Шаг 4 — бот + инлайн/виральность.
- ⏳ Шаг 5 — SQLite + Telegram Stars.

## Запуск прототипа

```powershell
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Открой `http://127.0.0.1:8000` в **двух вкладках**: в первой «⚡ Быстрый бой»,
во второй — тоже (или войди по показанному коду комнаты). Играй: выбирай 3
клетки и жми «ОГОНЬ!». Тайбрейк («Золотой раунд») включается автоматически.

Автопроверка сквозного матча без браузера:

```powershell
python scripts/ws_smoke.py
```

> Для реального Telegram Mini App нужен публичный **HTTPS**-адрес (туннель
> ngrok/cloudflared) — Telegram грузит Mini App только по HTTPS, и WebSocket
> должен быть `wss://`. Код комнаты можно передавать через дип-линк
> `https://t.me/<bot>/<app>?startapp=<CODE>` — фронтенд уже читает `start_param`.

## Деплой

Прод: **https://seablitz.duckdns.org** (Oracle Cloud, хост `oracle1`).
Схема сервера (общая с другими проектами): **nginx + certbot + systemd**, без Docker.

- Код: `/home/ubuntu/seablitz` — git-клон этого репозитория (доступ по deploy key).
- venv: `/home/ubuntu/seablitz/.venv`; секреты: `/home/ubuntu/seablitz/.env` (в git не хранится).
- systemd: `seablitz-web` (uvicorn на `127.0.0.1:8002`) и `seablitz-bot` (aiogram polling).
- nginx: сайт `seablitz.duckdns.org` (proxy + отдельный `/ws` с Upgrade), TLS — certbot.
- Шаблоны настройки — в `deploy/` (systemd-юниты, nginx-конфиг, `ssh_config` для deploy key).

**Обновление одной командой** (коммит → push → pull на сервере → перезапуск):

```powershell
powershell -File deploy/redeploy.ps1 "что изменилось"
```

Только выкладка, если push уже сделан самому:

```powershell
powershell -File deploy/update.ps1
```

Логи:

```
ssh oracle1 "sudo journalctl -u seablitz-web -f"
ssh oracle1 "sudo journalctl -u seablitz-bot -f"
```

> Состояние матчей хранится в памяти процесса, поэтому uvicorn запускается **одним
> воркером**. При масштабировании на несколько инстансов комнаты нужно вынести в Redis.
> Docker-вариант (`Dockerfile`, `docker-compose.yml`, `Caddyfile`) тоже есть в репозитории,
> но на текущем сервере Docker выключен и используется nginx + systemd.

## Вызовы друзей

- **⚡ Быстрый бой** — случайный соперник из очереди матчмейкинга.
- **⚔️ Создать вызов** — генерируется код комнаты; кнопка **«Отправить вызов
  другу»** открывает выбор чата (`switchInlineQuery`) и отправляет карточку с
  кнопкой «Принять бой», ведущей в эту же комнату.
- В любом чате набери `@<bot> blitz-<КОД>` — бот вернёт карточку вызова; друг
  жмёт «Принять бой» и попадает в ту же комнату (соперник уже ждёт).
- **Игра без Telegram (web / WhatsApp).** Играть можно прямо в браузере — WebSocket
  и статика загружаются в любом браузере. После «Создать вызов» доступны:
  «📨 Отправить вызов» (в вебе — WhatsApp), «🟢 Отправить в WhatsApp» (и в Telegram)
  и «🔗 Скопировать ссылку». Ссылка ведёт на `https://<DOMAIN>/room/<КОД>` — сервер
  отдаёт страницу с OG-превью (карточка в мессенджере) и сразу открывает комнату
  `/?room=<КОД>`. Игрок без Telegram просто открывает ссылку и вводит имя — и бой
  стартует. Web-вызов работает на том же коде комнаты, что и telegram-диплинк.


## Правила раунда и тайбрейк

Каждый раунд оба игрока **одновременно** стреляют по 3 клеткам поля соперника
(**10 секунд** на выбор; по истечении — сервер добивает случайными выстрелами).
Побеждает тот, кто потопил весь флот соперника. Чтобы убрать несправедливое
преимущество первого хода, залпы обрабатываются одновременно.

Если **оба** потопили последний корабль в одном раунде (обоюдный KO), ничьей
нет: показывается **картина сражения** (оба флота раскрыты + статистика), затем
**правила овертайма**, затем **«Золотой раунд»** — оба бьют по **одному общему
полю** за 10 секунд, побеждает тот, у кого больше попаданий. При полном равенстве
попаданий поле пересоздаётся и раунд повторяется. После боя всегда показывается
итоговая картина сражения и результат. **Ничьих не бывает — у партии всегда есть
победитель.**

После боя на общей картине крупно показан итог (**ПОБЕДА! / ПОРАЖЕНИЕ**) и можно
предложить **реванш**: проигравший жмёт «РЕВАНШ», победитель видит вызов и жмёт
«ПРИНЯТЬ РЕВАНШ» — новый матч стартует в той же комнате.

## Игровое ядро

```python
import random
from app.game import Match, MatchConfig

match = Match(config=MatchConfig(), rng=random.Random(0))

# оба игрока присылают свои залпы одновременно
result = match.resolve_round({0: [(0, 0), (1, 1), (2, 2)], 1: []})
# пустой залп игрока 1 добит случайными выстрелами (auto_filled)
print(result.players[0].hits, result.finished)

# безопасное представление для конкретного игрока (без кораблей соперника)
print(match.view_for(0))
```

## Баланс

Симулятор партий помогает подбирать `shots_per_round` и состав флота:

```powershell
python scripts/balance_sim.py --n 3000
```

Оценка тайбрейк-раунда при обоюдном KO (Golden round):

```powershell
python scripts/golden_round_sim.py
```

Результаты (общее поле, стратегия `smart`): повтор 3 выстрелами решается с
первого раза в ~60.6% случаев (в среднем 1.65 раунда), 5 выстрелами — 68.1%.
Повтор на том же поле использовать нельзя — после расстрела флота оба вечно
набирают по 0 (бесконечный цикл).

Результаты первых прогонов (стратегия `smart`, 3000 партий на конфиг):

| конфиг | ср. раундов | ничьи | партий ≤ 5 раундов |
|---|---|---|---|
| 3 выстрела, 3+2+1 | 6.96 | 29% | 5% |
| 4 выстрела, 3+2+1 | 5.38 | 38% | 54% |
| 5 выстрелов, 3+2+1 | 4.40 | 55% | 100% |
| 4 выстрела, 2+1 | 4.19 | 23% | 87% |
| 5 выстрелов, 2+1 | 3.46 | 31% | 100% |

Вывод: целевой темп «4–5 раундов» в чистых одновременных правилах даёт
30–55% ничьих. Для быстрого формата нужно правило-тайбрейкер (обсуждается
на шаге 2 — WebSocket-комнаты).
